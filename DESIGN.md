## Brand & Visual System (S7Tools Industrial Desktop)

This design system mirrors the dark technical aesthetic of the S7Tools Avalonia UI desktop application (VS Code Inspired Dark Industrial Theme).

### Aesthetic Principles
- **Dark Industrial Workstation:** Deep dark gray (`#1E1E1E`) canvas with elevated tool panels (`#2D2D2D`).
- **Brand Accent:** Cobalt Blue (`#007ACC`) used for primary triggers, active tabs, and selection states.
- **Micro-Telemetry Typography:** Monospaced fonts for memory offsets, address ranges, register dumps, and logging feeds.
